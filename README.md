# URL Shortener Service

This is a simple URL shortening service built using **Flask** and **MySQL**. The service allows users to shorten URLs, retrieve original URLs, update URLs, delete URLs, and get statistics (like the number of accesses).

## Features

- **Create Short URL**: Convert long URLs into shortened versions.
- **Retrieve Original URL**: Given a short URL, retrieve the original long URL.
- **Update Short URL**: Update the original URL associated with a short URL.
- **Delete Short URL**: Delete a previously shortened URL.
- **Get URL Statistics**: Get statistics such as the number of times a URL has been accessed.
